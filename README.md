# claraortiz.com

Versión unificada para publicación.

## Sistema visual
- Fondo desktop: `#ccc0b4`
- Fondo mobile: `#ebe1d8`
- Navegación y comportamiento responsive unificados en `site.css` y `site.js`
- Menú móvil consistente en todas las páginas: Inicio · Concepto · Estética · Contacto
- Logo de cada página vuelve al inicio
- Estado activo de navegación unificado

## Páginas
- `index.html`
- `concepto.html`
- `estetica.html`
- `contacto.html`

## Imágenes
Se conservaron modelo, rasgos, logo, isotipo, nombre y tipografía. Sólo se normalizaron las áreas de fondo conectadas a los bordes para evitar cambios de tono y franjas al adaptar la web a distintas pantallas. Las versiones corregidas se guardaron en PNG sin pérdida (`*-bg.png`): fuera de la máscara de fondo los píxeles de la modelo y de las fotografías se mantienen exactamente iguales al raster original.

Subir el contenido de esta carpeta tal cual a la raíz del sitio.
